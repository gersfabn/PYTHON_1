# Sistema de gestión para emprendimientos (Python)

## Requisitos
- macOS (como tu MacBook Pro 2017)
- Python 3.9+ instalado
- Visual Studio Code

## Cómo ejecutarlo
```bash
python3 sistema_emprendimiento.py
```

## Funciones
1. Registrar ventas
2. Registrar gastos
3. Ver ganancias
4. Exportar reporte CSV

## Archivos que genera
- `datos_emprendimiento.json`: base de datos local
- `reporte_emprendimiento.csv`: reporte exportado
